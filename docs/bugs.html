Free Trial API V1 — баги

5 багов в Users-методах v1, исправлено в v2.

Нажмите на эндпоинт → баги. Нажмите на баг → описание.

▶ POST /free/v1/api/users 3 бага
▶ MED Возраст меньше 18 принимается

Что сейчас: age=17 создаёт пользователя

Что должно быть: 400 Bad Request — age должен быть от 18 до 65

▶ LOW name не обрезается (пробелы сохраняются)

Что сейчас: " Alice " сохраняется с пробелами

Что должно быть: name.trim() перед сохранением

▶ LOW Нет ограничения длины name

Что сейчас: Можно сохранить name длиной 1000+ символов

Что должно быть: Максимум 100 символов

▶ GET /free/v1/api/users 2 бага
▶ MED limit всегда возвращает 1 запись

Что сейчас: users.slice(0, 1) — жёстко зашитый лимит, значение параметра limit игнорируется

Что должно быть: SQL LIMIT по переданному значению

▶ MED Content-Type: text/plain вместо application/json

Что сейчас: res.setHeader("Content-Type", "text/plain")

Что должно быть: application/json
